# 네이버 카페 키워드 크롤러

`crawl.py` (Selenium 기반)로 네이버 카페 게시판을 크롤링해서, 크롤링 시도마다 새 폴더에
`results.jsonl`을 저장한다. 이모티콘 제거와 광고성 글 필터링을 기본 전처리로 수행하고,
이전 크롤링 결과들과 URL 기준으로 중복을 제거한다. **CSV 변환은 이 스킬이 하지 않는다** —
사용자가 jsonl을 보고 원하는 컬럼을 별도로 요청하면 그때 변환한다.

## 트리거

사용자가 네이버 카페 URL과 키워드를 주면서 크롤링을 요청할 때. 둘 중 하나라도 없으면
먼저 채팅으로 물어볼 것 (URL, 키워드는 필수).

## 실행 절차

1. **URL/키워드 확인**: 사용자가 준 카페 게시판 URL(`https://cafe.naver.com/...`)과
   검색 키워드(쉼표로 여러 개 가능)를 확인한다. 없으면 채팅으로 물어본다.
   - 기간을 제한하고 싶다는 언급이 있으면 `--start-date YYYY-MM-DD`, `--end-date YYYY-MM-DD`로 전달.
   - 별도 언급 없으면 날짜 필터 없이 `--max-pages 50`(기본값) 안에서 전부 수집한다.

2. **최초 실행 여부 확인**: `.claude/skills/naver-cafe-crawler/naver_cookies.json` 파일이
   있는지 확인한다.
   - **없으면**: 최초 실행이라 로그인 창(Chrome 브라우저)이 화면에 떠야 한다. 사용자에게
     "Chrome 창이 뜨면 직접 로그인해주세요, 로그인하면 다음부터는 자동으로 백그라운드로 돕니다"라고
     미리 안내한 뒤 실행한다. `--headless`를 붙이지 않는다.
   - **있으면**: 자동으로 headless로 돈다. 그냥 실행하면 된다.

3. **백그라운드 실행**: 사용자의 프로젝트 폴더(현재 작업 디렉터리)에서 Bash 도구로
   `run_in_background: true`를 사용해 실행한다. 결과는 실행한 위치 기준
   `./crawl_results/<키워드>_<타임스탬프>/` 폴더에 저장된다.

   ```bash
   python "C:\Users\6153\Downloads\키워드\.claude\skills\naver-cafe-crawler\crawl.py" \
     --url "<카페 게시판 URL>" \
     --keywords "<키워드1>,<키워드2>"
   ```

   필요시 `--start-date`, `--end-date`, `--max-pages`, `--keep-ads`(광고의심 글도 저장하고
   싶을 때), `--ad-keywords "추가키워드1,추가키워드2"` 를 덧붙인다.

4. **진행 상황**: 백그라운드로 돌리는 동안 사용자가 다른 요청을 하면 처리하고,
   완료 알림이 오면 `run_meta.json`(저장/중복제외/광고의심 건수)과 `results.jsonl` 경로를
   사용자에게 알려준다. 로그인 대기 중(최초 실행)에는 사용자가 로그인할 시간을 줘야 하므로
   섣불리 실패로 판단하지 않는다.

5. **완료 후 안내**: 크롤링이 끝나면 다음을 반드시 사용자에게 알린다.
   - 결과는 JSONL로만 저장되어 있고 CSV로 자동 변환되지 않는다.
   - CSV가 필요하면 "이 jsonl에서 [원하는 컬럼들]로 CSV 만들어줘"라고 요청하라고 안내한다.
     (컬럼 후보: 제목, 링크, 본문, 조회수, 작성일, 댓글, 검색키워드, 광고의심, 수집일시)

## 주의사항

- `naver_cookies.json`은 로그인 세션이므로 다른 사람과 공유하거나 git에 커밋하지 않는다.
- 같은 게시판을 여러 번 크롤링해도 `crawl_results/` 아래 모든 이전 jsonl을 스캔해서
  URL이 겹치면 자동으로 건너뛰므로 중복 저장 걱정 없이 반복 실행해도 된다.
- 사이트 구조가 바뀌어 목록/본문이 비어 있는 레코드가 계속 나오면, `naver_cafe_debug.html`
  (페이지네이션 실패 시 자동 저장됨)을 열어서 CSS 셀렉터(`crawl.py`의 `CONTENT_SELECTORS`,
  `get_list_rows` 등)를 사용자와 함께 조정한다.
